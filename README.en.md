# Legend_Shot

Legend_Shot is a screenshot tool that allows users to capture the screen, annotate, and edit screenshots. It features an intuitive user interface with multiple functionalities such as selecting regions, drawing shapes, adding text, and saving or copying screenshots.

## Features

- **Screen Capture**: Capable of capturing the entire screen or a selected area.
- **Annotation Tools**: Provides various annotation tools including brush, rectangle, move, mosaic, and more.
- **Text Input**: Allows adding custom text directly onto screenshots.
- **Save and Copy**: Enables saving screenshots locally or copying them to the clipboard.

## Build Instructions

To build this project, run one of the following commands:

- `./build.sh setup_targets`: Set up build targets.
- `./build.sh build_linux_amd64`: Build for Linux AMD64.
- `./build.sh build_linux_arm64`: Build for Linux ARM64.
- `./build.sh build_windows`: Build for Windows.
- `./build.sh build_macos_arm64`: Build for macOS ARM64.
- `./build.sh build_macos_intel`: Build for macOS Intel.
- `./build.sh build_all`: Build for all platforms.

## Usage

After launching the application, you can use the provided tools to take screenshots and annotate them. Use the buttons in the toolbar to select different annotation tools, add text, or save and copy screenshots.
